# P8 · F8 记录查询实现计划

> **For agentic workers:** 按 `.agents/skills/executing-plans` 逐任务执行。步骤用 `- [ ]` 追踪。

**Goal:** 「我的学习记录」页三种查法：全部（日期倒序，当天多场并列并标「第 X 场」）/ 日期区间（列表 + 汇总：完成天数、累计时长、完成率）/ 指定日期（单日详情，支持 `/records?date=` 直开）；起止颠倒自动纠正并提示；空结果显示「还没有记录，今天这 5 分钟就是第一条」。

**Architecture:** 后端新增 `GET /api/records`（无参=全部；`date_from`+`date_to`=区间；`date`=单日），服务端按归属日分组、场内按 `started_at` 升序编 `seq`（「第 X 场」由服务端给出），join DayTask/Reflection/Star。前端重写 RecordsPage 为三模式视图。

**Tech Stack:** FastAPI + SQLAlchemy；React 18（原生 date input，不新增组件库）。

**Spec:** [docs/specs/008-f8-records.md](../../../docs/specs/008-f8-records.md)（执行时从模板复制）。

**Depends on:** 全部前序（P3 归属日与有效性、P4 感想、P5 star、P7 `/records?date=` 跳转约定）。

**Produces（后续计划依赖的接口）:** 无（收尾功能，dev-order 第 8 位）。

## Global Constraints

- 同 P1 全部；另：记录只读，不提供任何编辑入口（感想 A19 只读）；有效场次 = `status IN ('completed','settled') AND ended_at IS NOT NULL`，discarded 与进行中场次不出现在任何查询结果；「第 X 场」编号与归属日分组只在服务端计算。

## Review Focus

1. 起止颠倒（from > to）→ 自动交换并 `corrected=true`，不报错（Task 2 钉住）。
2. 区间边界含头含尾（闭区间），跨月区间正确（Task 2 钉住）。
3. 同一天 3 场有效 → `seq` 1/2/3 按开始时间升序，横向并列展示（Task 2 + Task 3）。
4. 无数据区间 → `days=[]`、summary 全 0，前端空态不渲染 0 值表格（Task 2 + Task 3）。
5. 完成率口径 = 有有效场的自然日数 ÷ 区间自然日数（单日模式不返回 summary）（Task 2 钉住）。
